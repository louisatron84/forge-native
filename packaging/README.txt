Forge native — development build

Windows: run the setup executable, or extract the portable ZIP and run forge.exe.
Requires Windows x64 and the Microsoft Visual C++ 2015–2022 x64 runtime.

Linux: install the Debian package with your package manager, or extract the
portable archive and run ./forge. Portable builds require the desktop libraries
listed in docs/DISTRIBUTION.md in the source repository.

macOS: open the disk image and drag Forge to Applications. Choose the build for
Apple Silicon or Intel. Unsigned development builds have not been notarized.

Install Python 3 separately to run Python projects. Install Git separately for
source control. Forge discovers these tools on your machine.

Your projects and settings are kept when Forge is uninstalled.
