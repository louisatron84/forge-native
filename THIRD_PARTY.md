# Third-party software

Forge is built on these projects. Each keeps its own licence. The list is
kept up to date as dependencies are added; before each release it's checked
against `cargo about` (or similar) output.

| Component | What for | Licence |
|---|---|---|
| GPUI (Zed Industries) | The user interface toolkit | Apache-2.0 |
| basedpyright | The Python language server, run as a separate program | MIT |
| debugpy | The Python debugger, installed into the user's environment | MIT |
| alacritty_terminal | The terminal's screen model | Apache-2.0 |
| ropey | The text buffer | MIT |
| Velopack | Installers and updates | MIT |
